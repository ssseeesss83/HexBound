# 剧本 + AI DM：玩法重新设计

设计版本：D1.0，2026-10-24。本文描述目标行为，尚未代表产品已实现。实现基线为 `917a24d`（v0.6）。

## 产品方向

玩家围绕一份有大纲、主线与关键事实的剧本自由行动，AI 持续扮演 DM。产品只保留这一种跑团形式。剧本决定世界的起点、关键冲突和人物目标；玩家的行动决定如何参与冲突以及故事的实际后果。

开团只需选择剧本、角色、起始等级和桌务设置。预设剧本、作者剧本、AI 辅助编写剧本是内容制作来源，不再成为不同玩法。玩家端移除“预设 / 自由 / 混合”“引导 / 创作 / LLM 引导”等模式切换。没有模型连接时明确显示本地演示主持，生产 AI DM 能力须通过真实模型验收。

## 一次完整跑团循环

1. AI DM 描述角色可见的当前场景和局势，给出少量可选提示。
2. 玩家在队内文字频道中商量，也可以各自准备行动草稿。本次暂不实现分队语音。
3. 玩家通过能力表选择，或在行动框自由描述目标、方法与对象。
4. DM 判断意图是否成立、是否需要检定及预计后果；服务端根据规则生成可执行方案。
5. 需要确认的资源消耗和不可逆行动由玩家确认；规则引擎执行检定、战斗与资源结算。
6. DM 根据已提交结果叙述后果，更新已确认事实，推进或扩展剧情节点。

聊天不触发检定，不改变世界，不消耗动作。角色对 NPC 的实际发言通过行动区提交，避免把玩家商量误当作角色已经说出口。无需检定的合理互动直接推进；没有风险或失败后果的行为不强制掷骰。

## 有准备的即兴主持

剧本初始化只建立关键主路径、当前可玩场景、必要条件和预设怪兽卡。分支可汇合，编辑器以树状导航展示，汇合点显示引用，保持同一节点身份。

节点分为关键节点、普通场景、待续写末端与结局。末端保存事实摘要、未解决线索、NPC 目标、可用怪兽、后续关键节点候选与续写约束。玩家接近末端或表现出明显偏离意图时，后台生成一小段候选子树。生成保持低优先级，随时让位给玩家操作。没有命中预生成分支时，实时 DM 处理眼前行动，并请求最小必要的续写。

主线保存重要冲突与结果条件，不规定唯一解法。例如“取得透镜”可来自谈判、交换、偷取或冲突；没有透镜也可形成另一种有后果的结局。检定失败不能反复要求重掷直到回到预定路线。

AI 可以丰富 NPC、环境、选择与规则内的不确定性，不能改骰点、凭空修改角色资源或把叙事文本直接当作机械效果。

## 规则资料与裁定

用户已确认沿用 2014 版。本次公开基础资料范围选定为 SRD 5.1 全集：完整保留该范围中的职业、子职业、特性、法术、18 项标准技能和关联规则。该范围与 2014 Basic Rules、完整 PHB 及商业扩展分别登记，不将每职业一个 SRD 子职业称为所有出版物的全部子职业。

先收集并核对完整资料，再执行结构化导入。资料收录、角色构筑和机械执行分别验收。目录中存在某法术，不能据此宣称已经能按规则施放。

所有战斗数值通过确定性的规则系统结算。AI 根据环境提出合法目标、策略与需要裁定的情境参数；引擎决定资格、骰式、加值、消耗与状态变化。尚无处理器的效果不能交给模型编造数值。

## 多人桌边体验

交流区和行动区独立呈现。非本人回合仍能聊天、阅读和准备草稿；实际行动按动作、附赠动作、移动及合法反应窗口校验。

成员可分成不同小队，各自进入场景实例。场景、遭遇、文字和 DM 记忆均按权限区分。房主负责桌务，不因房主身份自动获得其他小队秘密。跨队通信需要明确的桌务约定或游戏内能力。

用户于 2026-10-24 补充：**分队语音本次暂不实现**。本轮不引入语音基础设施、媒体连接或语音验收；未来语音接入复用频道成员关系。

## 评审后的实施原则

- 作者发布的剧本冻结；生成内容写入房间扩展图。节点、边、事实和生成任务分别版本化。
- 先建立场景实例和服务端可见性，再做分队动态图。两队不能共用一个当前场景或一个战斗状态。
- 聊天序号与行动版本分开；聊天不使有效行动、提案或 DM 回复失效。
- 当前场景尚可交互时，后台续写不阻塞玩家。玩家触及未生成出口时，仅请求当前必需的最小续写，并展示明确等待与重试。
- “主线条件”约束因果，不强制走固定按钮；关键事实可以被玩家知情改变，变化必须有事件依据和后续响应。
- 资料完整性先对照官方范围与关系，再做导入；当前社区快照的数量不能替代官方全集核对。
- 未支持机制可在开发版本明确拒绝，但不能靠拒绝把正式大版本标成“全部严格规则已完成”。
