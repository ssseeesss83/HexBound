## A：行为与集成验收

| ID | 情境 / 操作 | 必须观察到的结果 |
|---|---|---|
| A01 | Windows LF / CRLF 配置分别检出来源包 | 原始哈希、字节数、许可与固定来源一致；不能改 manifest 来通过 |
| A02 | 原始资料被改一个字节、删一个文件、改记录数量 | 审计阻止正式导入，明确定位差异 |
| A03 | 对照官方范围清单，移除一个子职业特性或一段法术正文 | 完整性门禁失败；总数相同也不能漏过 |
| A04 | 全量导入，重复同版本导入，中途注入失败 | 完整启用 / 幂等不重复 / 失败回滚；旧规则包仍可读 |
| A05 | 查询每职业 1–20 级、18 技能、所有子职业、特性和法术关系 | 与最终来源清单一致，无重复或悬空引用；每条保留原文与出处 |
| A06 | 同能力在目录、人物卡、动作菜单、AI 工具查询 | 支持状态及资格一致；包外 handler 不能混入 |
| A07 | 一人持续聊天，另一人提交已合法的行动，DM 同时回应 | 聊天不改 action revision，动作不因闲聊冲突，DM 不因闲聊被作废 |
| A08 | 战斗非本人回合连续聊天、编辑草稿 | 不扣行动资源，不触发检定或 DM 执行工具；草稿不变成行动 |
| A09 | A/B 两队分别在不同场景；A 请求快照、WS、历史、导出、人物卡、提案 | 不返回 B 的秘密、目标、资源、事件数量或隐私片段；错误响应也不泄漏 |
| A10 | 成员调队、离队、权限撤销，在途分页与 WS 仍存在 | 旧 epoch 请求拒绝；新队历史不默认追溯；旧缓存和控件销毁 |
| A11 | 在 B 场景植入唯一秘密词，抓取 A 的 DM 请求及全部输出 | A 的模型输入和叙事不含秘密；规划器的隐藏文本不直接发布 |
| A12 | 房主位于 A，尝试读取 B 场景或人物完整构筑 | 房主桌务身份不自动授予该读取权限 |
| A13 | 授权历史多页读取；期间另队大量聊天，再次改变权限 | 无漏页和重复，游标绑定身份 / 频道 / epoch，不能跨频道重放 |
| A14 | 新开团、旧模式恢复、直接调用旧模式 API | 新房间只有剧本 + AI DM；历史保留进度；旧参数不能绕开新权限 |
| A15 | 两种入口提交相同攻击；重复 command；非本人动作；合法反应窗口 | 同一规则计划；成功只结算一次；非法动作拒绝；别人回合合法反应可执行 |
| A16 | 点击察觉，自由描述无风险开门，重复已失败调查，意图含多个行动 | DM 判断是否检定；无风险不强迫骰点；重复依据事实变化；复杂计划明确拆分 |
| A17 | 提案后角色失能、资源用完、目标离场、回合改变或跨场景重放 | 确认时重查并拒绝过期计划，不扣费、不重掷；普通聊天不令其过期 |
| A18 | 编辑含汇合与循环的主线图，保存发布导出再导入 | 节点身份和所有字段保留；树引用不复制；非法条件 / 依赖定位到节点 |
| A19 | 仅主路径和 frontier 的剧本发布 | 不要求生成所有分支；缺续写契约的末端拒绝；frontier 不变成空场景或结局 |
| A20 | 玩家选择未预设的谈判 / 跟踪方案，含失败后果 | AI 在大纲因果内提供新路径，可进入生成支线；不强迫回原按钮 |
| A21 | 已检定成功但出口未生成，超时、重试、刷新、服务重启 | pending transition 恢复；前置骰点不重掷、不重复扣费；生成后不自动移动 |
| A22 | 模型返回重复 ID、包外怪物、任意伤害、改已访问节点、矛盾事实 | 补丁整体拒绝；世界无部分变化；已结算行动保持有效 |
| A23 | 当前续写失败，玩家观察、讨论、取消等待或尝试其他路径 | 当前可玩场景和合法动作保留；明确展示等待 / 恢复状态；不编造已成功转场 |
| A24 | 接近末端与偏离主线触发多次预取 | 有界 1–3 节点浅层生成，同版本去重，不递归铺满 |
| A25 | 后台模型被人为阻塞，玩家立即提交战斗动作或实时 DM 请求 | 动作不等后台；取消资格生效；旧调用不占实时逻辑许可 |
| A26 | 生成期间事实变化、调队、换场景、服务崩溃或重复回调 | 过期结果不能落稿 / 发错受众；lease 恢复；同 job 不重复加节点 |
| A27 | 两队争同一物品、分别造成全局事实改变，再合队 | 唯一物品只授予一次，冲突返回当前事实；知识和局部战斗正确合并 |
| A28 | 一队战斗、一队长休或快进；存在世界时限 | 在共同时间边界协调，不能跳过战斗方的反应或使共享 NPC 出现矛盾 |
| A29 | 每个来源条目核对能力覆盖矩阵，执行正向 / 拒绝 / 边界 / 交互测试 | 所选范围全部有明确规则处理；无未完成 reference 冒充完整；R01–R12 通过 |
| A30 | 迁移进行中旧房间，随后执行备份恢复 | 人物资源、奖励去重、骰点、剧情进度保留；历史规则标明，不混入新机械规则 |
| A31 | 检查每个声称完成的小版本 | 有独立 commit、任务记录、相关测试结果及已知问题；未完成不打版本标签 |
| A32 | 推送设计 / 完成后的产品版本并核对远端 | 远端分支 HEAD 与本地一致；推送失败如实记录，不称已上传，不自动部署 |
| A33 | 同场景 A 独自识破秘密，B 仍未知 | B 的 DM 请求、公共叙述、通知、历史与导出不含秘密；公共回应基于受众知识交集 |
| A34 | 同一 NPC 已在 A 的遭遇中，B 队到达并攻击 | 只有一份实体和权威遭遇；按同步点加入 / 等待，不复制 NPC、死亡和奖励 |
| A35 | 发起 HTTP / 分页 / 命令重放后调队，旧请求才返回 | 返回前重新检查 epoch，不能重放旧私有快照；延迟 DM 输出不能发往错误受众 |
| A36 | 同场景私密事件和另队消息持续产生 | 本人的可见序号、游标内容、未读数、计数和错误信息不暴露那些事件 |
| A37 | 武器命中后选择神圣惩击，命中时护盾术，施法完成前法术反制 | 规则窗口顺序正确；步骤可暂停恢复；选择前不预扣可选资源；重试不重掷 |
| A38 | 探索中施放持续法术后转场 / 分队 / 进入战斗 / 休息 | 共享时钟正确驱动专注、到期和解除；场景切换和轮计数重置不改变实际持续时间 |

## R：规则机械覆盖矩阵

| ID | 覆盖族 | 需特别验证的交互 |
|---|---|---|
| R01 | 检定、技能、豁免、优势 / 劣势与熟练 | 普通检定的自然 1/20；专精；同来源效果不可重复叠加 |
| R02 | 武器 / 法术攻击及伤害流程 | 自然 1/20、额外攻击、暴击骰、不同伤害类型、免疫 / 抗性 |
| R03 | 动作、附赠动作、移动、反应 | 行动额度、回合触发、机会攻击、非本人反应窗口、重复请求 |
| R04 | 空间、目标、视线、距离与区域 | 体型、触及、掩护、友伤、移速变化、合法目标和区域重复触发 |
| R05 | 施法与持续 | 已知 / 准备、法术书、成分、材料消耗、仪式、法术位、契约位、升环与时间限制 |
| R06 | 专注、状态、驱散、防护与叠加 | 受伤豁免、失能、到期、替换、抗性与伤害的先后顺序 |
| R07 | HP、临时 HP、倒地、死亡与恢复 | 稳定、死亡豁免、再次受伤、立即死亡、治疗、复活前提 |
| R08 | 休息、资源与世界时间 | 职业差异、长短休条件、持续效果及不同场景时间同步 |
| R09 | 完整合法建卡及成长 | 种族 / 背景 / 装备 / 专长、职业和子职业、所有等级、可选规则前提 |
| R10 | 特性、选择项、被动与职业资源 | 每条授予关系、触发时机、次数恢复、条件性效果与互斥 |
| R11 | 标准怪物与受控单位 | 原始完整动作 / 特性、传奇等适用机制、资源、召唤 / 变形与控制者 |
| R12 | 信息、社交、长期与特殊能力 | 规则内 DM 裁量转结构化事实；知识受众、材料、时间和特殊句段不丢失 |

矩阵以最终选定资料全集为闭包。某格“不适用”必须引用具体范围依据；不能以“复杂”或“不常用”为理由不实现却标为通过。测试从官方规则例子和真实交互推导，避免只重复实现里的公式。

## 性能与主持体验的测量

- 在相同环境下比较无后台任务与阻塞后台任务时的玩家命令延迟；规则动作等待不得依赖后台远程响应。记录 p50 / p95 和最大值，正式阈值由 P00 基线及 P07 压测确定。
- 用 fake provider 精确控制取消、重排、超时和重复返回，再用真实 provider 验证取消后逻辑容量。日志不记录密钥。
- 场景 DM 不替玩家决定动机、不泄露隐藏结局；动作后叙述遵循已确认结果。剧情质量通过真实多人试玩记录，不以 schema 通过代替。
- 单次生成的节点、深度、token、超时、重试与队列规模均有硬预算；达到预算后保持当前场景可玩并说明续写状态。
