# 账号与授权独立评审

日期：2026-10-23。评审对象：新增账号模块、房间身份绑定、工坊权限依赖、账号前端和对应测试。采用代码审查与本地 API 测试；不是外部渗透测试认证。

## 已检查的边界

| 项目 | 检查结论 |
| --- | --- |
| 密码存储 | 独立随机盐与 scrypt，不保存明文；KDF 在线程执行并限制并行量，避免直接阻塞游戏事件循环 |
| 登录会话 | 随机不透明会话 ID；数据库存其摘要；浏览器使用 HttpOnly Cookie，服务端检查期限和账号状态 |
| CSRF | 已登录的写操作要求与会话绑定的 X-CSRF-Token；有 Origin 时检查完整协议与主机；跨站登录/注册同样检查 Origin |
| 注册权限 | 新注册账号固定 player，注册请求不能指定管理员角色；初始化管理员只能来自部署配置，不把首次访客自动提升为管理员 |
| 授权 | player 可游玩，creator/admin 可管理共享内容，只有 admin 可管理账号；服务端检查，不依赖隐藏按钮 |
| 角色与禁用 | 管理修改需要 expected_version，事务中复核管理员身份；变更角色或禁用后撤销目标全部会话 |
| 最后管理员 | 使用写事务保护最后一个未禁用管理员，不允许降级或禁用导致无管理员 |
| 强制改密 | 管理员重置后标记强制改密；仅身份查询、改密及退出接口可用，游戏、工坊、管理与 WS 均应拒绝 |
| 旧 Bearer | 安全默认不开放访客/旧管理员 token；即使显式迁移模式，已有无效账号 Cookie 也不能回退旧凭证 |
| 房间归属 | 一个账号在同房间只能拥有一个席位；跨账号读取/恢复拒绝；旧席位认领后旧 token 不再认证 |
| WebSocket | 连接时、广播前和连接循环中复核账号会话；注销或禁用后终止连接，不能继续接收游戏快照 |
| 可见数据 | 成功账号 API 与审计不返回密码 hash、会话 secret；CSRF 令牌可供同源前端读取，但不能单独用于登录 |

## 评审发现与处理

1. **密码操作在途吊销竞态（已修复）**：初版改密/管理员重置在等待 KDF 后只复核账号状态。若期间退出全部设备，账号角色和版本不变，已撤销请求仍可能提交。现已将发起会话摘要纳入事务内有效性检查，提交前确认会话仍存在、归属一致且未到期。
2. **Origin 只校验主机（已修复）**：初版忽略协议，现按完整同源关系校验；WebSocket 的 ws/wss 转换为 http/https 后比较。
3. **密码输入在 422 中回显（已修复并独立复验）**：独立请求证实默认 FastAPI 验证错误会把不合法密码放入 `detail.input`。应用现在统一剔除验证错误的原始输入与上下文，只返回字段路径、错误类型和说明。修复后用同一不合法密码请求复验：422 保留，响应不含该密码，错误对象仅有 `loc/msg/type`。
4. **旧回归不能替代默认鉴权验证**：旧匿名测试显式启用兼容模式以维持回归，因此独立账号测试必须在安全默认下运行，不能仅根据旧测试全部通过宣布授权完成。

复核结论：本轮发现的阻断问题均已修复。房间加入与席位认领现于取得房间锁后再次鉴权；工坊生成在模型返回后再次鉴权，避免等待期间撤销权限后继续执行。

## 未验证的部署与产品边界

- 未做公网流量、分布式暴力尝试、反向代理错误配置或长期压力下的安全验证。
- HTTPS 部署需要启用 Secure Cookie，并正确配置可信代理；本地 HTTP 开发与生产 Cookie 设置不能混淆。
- 进程内限流适合当前单实例部署；不能替代入口限流、多实例统一计数或异常登录监控。
- 当前没有邮箱验证、MFA、找回密码邮件或单设备会话管理；恢复依赖管理员重置与重新登录。
- 管理员和创作者管理的是同一份共享内容工坊，并非每个作者私有的多租户内容空间。
- 暂未完成真实浏览器安全头、Cookie 和跨站行为的完整兼容性验收。
