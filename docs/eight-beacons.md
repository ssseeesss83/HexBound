# 《雾港八灯 · 归航战役》

八章长篇，**32场独立战斗、36种不同SRD来源敌人、8场章末Boss、8个推理解谜**。3级起步，推荐4人，支持1–6人；章节成长使XP模式约至9级。需分多次游玩，自动存档。它替代短篇作为首页默认推荐，旧《归航之夜》仍可选择；不是原先2–4小时短篇。

主线只有一个目标：恢复八处航标，击败封锁海湾的黑龙，让归船回家。阿苇负责救援，伊岚负责设施，不引入复杂政治支线。每章四场战斗，第二、第四场后返回安全补给站；首次停留一天并恢复，章末另发成长XP/资格。可在人物卡逐级升级和管理法术。刷新不会重置补给、谜题、敌人或装置。

这32场均有独立地点、敌人出生和完成记录，不靠重复刷新、读档或同一敌人的换名凑数。当前主线依次经过全部32场，最终可选择修复或封存核心，两种结局都让归船回港。没有要求角色永久牺牲。

每个谜题有现场明确线索、2–3个操作方案，正确推理直接成功，不再掷骰随机决定正确答案；错误方案首次造成最多2点擦伤（不会致死）并给出提示。同一错误不能重复扣血，正确解法始终可用。交流频道先商量，领队再提交实际操作；领队阵亡时由首位存活队员代行解谜和路线操作。

## 战棋操作

- 新遭遇显示平面5尺网格，蓝格是当前可达位置。选择“移动”，点击空格，审核确认后消耗对应移动；困难地形双倍，斜走不穿墙角，移动远离擒抱目标后解除擒抱，不自动拖拽。
- “选择目标/施放”中切换能力预览，金色格显示射程与视线。点击敌人可提出攻击，选择法术会打开既有法术位/多目标确认。服务端再次检查范围和资源，不以颜色提示直接结算。
- 也可以在自由行动描述“移动到（4，2）”，列、行从1开始，生成同一份移动计划。普通攻击、治疗与其他自由动作仍必须满足距离及动作预算。
- 红色预警格在下轮爆发前给队伍移动机会。靠近◈装置5尺内可消耗一个动作关闭；两处装置关闭后护盾/场地持续效果停止，撤销装置产生的待爆预警；黑龙自身吐息仍保留。Boss半血强化一次，保存后不会重新触发。
- 敌方由DM的服务端战术代理寻路、选择合法目标并执行冻结动作，AI可解释已发生的结果；目前不额外调用模型决定每个敌人回合。敌人不会瞬移玩家。没有合法射程或通路时会守候并正常结束回合。

公开简化：单格体型、同一高度；每格及对角线均5尺；不实现机会攻击、飞行高度和完整掩护几何。多目标法术受统一范围限制，火球需同一20尺区域、闪电束需同一直线、锥形需同一方向。尚未登记的物件变化不会靠自由叙述生效。

## 36种敌人及执行范围

盗匪、守卫、斥候、暴徒、匪首；地精、大地精、熊地精、狼、凶暴狼、巨蜘蛛；巨鼠、鼠群、灰泥怪、赭冻怪、胶质方块、拟态怪；骷髅、僵尸、食尸鬼、妖鬼、尸妖；活化盔甲、飞剑、扼杀之毯、石像鬼、牛头人；沙华鱼人、海生魔人、鹰身女妖、海鬼婆；火/气/土/水元素；幼年黑龙。

均有唯一真实SRD来源ID，使用已冻结2014版资料取材；每张卡保留原始HP/AC及预设说明。**它们是可执行的战役预设，非完整官方怪物自动化**：HP/AC/伤害有战役调校，入场按1–6人冻结生命缩放；单人额外降低伤害骰。不会在战斗中随加入/离开偷偷重算。

执行配方包括近战/远程、有限多次攻击、近邻协攻、冲撞倒地、远程撤位、一次束缚、短暂中毒、僵尸一次坚韧、汲取恢复、斩击/闪电触发冻怪一次修复、预警吐息、护盾减伤及来源免疫。源规则更复杂的吞没、永久生命上限降低、死亡凝视、飞行与传奇动作没有伪称实现。幼年黑龙无传奇动作，场地装置是公开冒险规则。

为避免纯近战队伍遇到斩击免疫敌人无解，本战役配发“航标铜锤”：5尺、1d6钝击、消耗一个动作、无次数限制，可在能力栏使用。先查看敌方预设与战术提示，准备好不同伤害方式。

自动化整团采用固定测试骰验证可达性，不代表真实难度或游玩时长。实际玩家的平衡与节奏反馈仍需继续收集。分队语音本轮不实现。
