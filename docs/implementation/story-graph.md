# 稀疏剧情图实施记录

P05a 首批实现位于 `backend/story_graph.py`。这是作者资料契约，不执行剧情条件、不调用模型、不写房间、资源或骰子。

## 当前契约

- `StoryBook` v2 明确绑定规则集和规则包，保存大纲、事实定义、里程碑、NPC 目标、声明的物品 / 事件 ID、结局约束、节点及边。
- 节点分 key / scene / frontier / ending。关键节点需要目标、推进条件和失败后果；续写出口携带摘要、未解线索、引用、约束及可选 fallback。结局和续写出口不得有后继，续写出口不能充当入口。旧结局的展示对象无损保留，续写出口不含环境对象。
- 条件仅支持 all / any / not / fact_equals / has_item / event_occurred / milestone_state。没有代码求值。深度最多 12、每树最多 128 项、每逻辑节点最多 32 子项，整个资料最多 1 MB。先限制原始容器再递归解析，拒绝非 JSON 值。
- 事实类型、可变性和可见性分别保存；世界前提不得可变。布尔值与整数不互当。引用分命名空间检查；里程碑包含 pending / achieved / failed / bypassed。
- 每个节点必须结构上可从入口到达，且有到结局或续写出口的路径。有出口循环允许；导航显示循环 / 汇合引用，避免复制与无限展开。主路径只是导航标记。

这些检查只证明声明与拓扑成立，不能证明所有条件组合都能达成，也不能证明自由文本叙事因果。物品 / 事件 ID 在这里是作者声明；P06 需再验证冻结包与实际运行来源，声明不授予物品。

## 兼容迁移

`migrate_legacy` 返回独立草稿，不改变输入、发布历史或房间。节点、对象、怪兽列表和完整旧行动保存，直接 / 成功 / 失败各生成兼容边；同目标的成功与失败不会去重。边 ID 使用稳定位置序号，避免局部动作同名或 64 字符 ID 超限。默认绑定历史规则包，不把旧自定义技能提升为严格 SRD 能力。

v2 重复迁移返回等价数据，未知 schema 拒绝。当前仍未将 v2 接入 `MODELS` 或旧编译器；旧解析器明确拒绝 v2，避免空续写出口被当作普通场景运行。后续 P05b 接入作者草稿和树编辑器，P06 接房间扩展图后再开放对应发布 / 运行能力。

## P05b1 作者草稿接入

当前 `parse_card` 已按 schema_version 将 v2 作者草稿分发到 `parse_draft`，`MODELS` 中的旧运行模型不变。`parse_draft` 检查有界严格结构，允许暂未连接的拓扑保存；`parse_book` 和工坊校验再报告引用与拓扑问题。完整有效的图草稿可通过内容包导入 / 导出；未完成拓扑可保存、导出，但导入仍拒绝。

工坊的“创建独立图草稿”调用受作者权限与来源 revision 保护的接口，写入新 ID 的独立内容及历史记录，不更新旧条目。沿用既有保存、版本冲突、复制、归档与历史机制。基础表单提供大纲，原始数据区可编辑其余声明，树状表单在 P05b2 接入。

v2 发布接口和内容编译器仍明确阻挡，`campaign.validate_package` 再做运行入口防御。未接入 P06 前不能将 frontier 当场景开团；作者草稿不进入公开开团列表。

## P05b2 树状编辑器

`frontend/story-editor.js` 提供有限展开的树导航和选中节点面板，包含四类节点、主路径、怪兽引用、事实 / 里程碑 / NPC 目标声明、条件树、续写约束及 fallback。分支折叠状态随表单重绘保留；导航不标记未保存修改。汇合与循环显示引用，不复制底层记录。

重命名前先检查合法性和同类唯一性，再更新入口、连接、旧行动出口、条件及续写引用。拒绝的中间 ID 不改变数据和引用。事实类型改变后保留旧比较值并显示不匹配提示，用户重新填写时按事实声明类型解析；不会将数字输入按旧布尔值类型吞掉。

旧检定的目标修改同步原行动出口。转换普通连接时明确确认整项原行动的全部结果，取消不改数据；确认后移除对应旧行动桥接绑定，要求作者重新配置条件。终端转换前须移除不相容内容，不静默丢失遭遇、对象或连接。环境对象详情目前保留原始数据编辑。

`npm run test:story-editor` 使用实际 DOM 控件编辑，并把最终结果交给后端 `parse_book` 验收；另有完整工坊 DOM 冒烟和本机浏览器视觉检查。版本差异、校验定位和预览细化仍待下一批。

## P05b3 版本差异、定位与作者预览

版本记录可只读比较任一历史稿与当前草稿。含 ID 的数组按稳定 ID 比对，单独列增删、字段变化与共同 ID 的相对顺序变化；增删与重排同时发生也不会漏报。最多显示 200 项并明确截断，正文全部转义。

校验结果可切到对应节点及连接 / 条件 / 声明控件，前缀相同的 ID 不互相误命中；无法精确映射的项目转到原始数据。选中节点的作者预览包含全文、条件、分支、怪兽与续写信息，明确标注含秘密，不求值、不掷骰、不转场。

历史读取和恢复绑定发起时的 item / revision。切换条目或离开历史页后的旧响应不会复活旧面板，恢复请求仍指向最初授权点击的内容版本。

## P05b4 原生稀疏草稿与辅助编写

工坊可直接新建“场景 → frontier”的两节点骨架，模板绑定当时已激活的规则包，不激活候选规则。原生草稿不需要经过旧格式迁移；占位文字明确提示作者补写。

辅助生成请求显式指定 schema_version=2，服务端冻结规则包常量，最多 12 节点 / 24 边，至少一个合法 frontier。模型只能引用现有已发布技能 / 怪兽，不得生成迁移兼容行动；完整拓扑、续写及依赖校验通过后才返回。返回前重新检查作者权限和当前依赖，不自动保存、发布或开团。

普通作者 v2 仍可编写完整结局；“必须有 frontier”仅限制稀疏辅助生成模式。手工迁移兼容检定亦检查 check 类型，不能将攻击卡作为检定引用。关闭弹窗或改选其他内容后迟到的生成结果不会替换新草稿。

辅助生成目前以可控 provider 测试门禁，真实服务与整团叙事质量仍归 P11。A18 / A19 的发布与运行联合验收须在 P06 接入后关闭；当前发布保护继续生效。
