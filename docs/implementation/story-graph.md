# 稀疏剧情图实施记录

P05a 首批实现位于 `backend/story_graph.py`。这是作者资料契约，不执行剧情条件、不调用模型、不写房间、资源或骰子。

## 当前契约

- `StoryBook` v2 明确绑定规则集和规则包，保存大纲、事实定义、里程碑、NPC 目标、声明的物品 / 事件 ID、结局约束、节点及边。
- 节点分 key / scene / frontier / ending。关键节点需要目标、推进条件和失败后果；续写出口携带摘要、未解线索、引用、约束及可选 fallback。结局和续写出口不得有后继，续写出口不能充当入口。旧结局的展示对象无损保留，续写出口不含环境对象。
- 条件仅支持 all / any / not / fact_equals / has_item / event_occurred / milestone_state。没有代码求值。深度最多 12、每树最多 128 项、每逻辑节点最多 32 子项，整个资料最多 1 MB。先限制原始容器再递归解析，拒绝非 JSON 值。
- 事实类型、可变性和可见性分别保存；世界前提不得可变。布尔值与整数不互当。引用分命名空间检查；里程碑包含 pending / achieved / failed / bypassed。
- 每个节点必须结构上可从入口到达，且有到结局或续写出口的路径。有出口循环允许；导航显示循环 / 汇合引用，避免复制与无限展开。主路径只是导航标记。

这些检查只证明声明与拓扑成立，不能证明所有条件组合都能达成，也不能证明自由文本叙事因果。物品 / 事件 ID 在这里是作者声明；P06 需再验证冻结包与实际运行来源，声明不授予物品。

## 兼容迁移

`migrate_legacy` 返回独立草稿，不改变输入、发布历史或房间。节点、对象、怪兽列表和完整旧行动保存，直接 / 成功 / 失败各生成兼容边；同目标的成功与失败不会去重。边 ID 使用稳定位置序号，避免局部动作同名或 64 字符 ID 超限。默认绑定历史规则包，不把旧自定义技能提升为严格 SRD 能力。

v2 重复迁移返回等价数据，未知 schema 拒绝。当前仍未将 v2 接入 `MODELS` 或旧编译器；旧解析器明确拒绝 v2，避免空续写出口被当作普通场景运行。后续 P05b 接入作者草稿和树编辑器，P06 接房间扩展图后再开放对应发布 / 运行能力。
