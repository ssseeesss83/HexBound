## P03b · 闲聊与行动版本分离

- schema 4 为旧房间初始化 `action_revision`；存储版本继续服务事务及快照排序，消息沿用成员本地序号。
- 闲聊不要求匹配旧存储版本，也不推进行动版本。新版客户端提交所见行动版本；在同伴聊天期间提交的合法行动仍可执行，真实行动冲突仍拒绝。旧客户端未提供行动版本时仍执行原有存储版本检查。
- 在途 DM 回应核验行动版本和固定受众权限范围：聊天不会使回应过期，暂停或受众权限代次变化则丢弃。生成后的新场景推进行动版本，单纯叙述不会推进。
- 导演提案的事实指纹增加受众范围；模型等待期间若权限变化，不发布过期提案。受众指纹不含聊天序号，避免聊天重新触发失效。
- 专项 **62 passed**，覆盖闲聊后的旧快照行动、真实行动冲突、聊天 / 暂停 / 撤权与慢模型并发。受影响 5 组界面冒烟再次通过。专业只读复审另跑 **40 passed**，未发现当前单队接口的高优先级越权。
