# 战棋与长篇战役迭代

按 2026-10-26 需求，将首推内容改为八章长篇战役。至少 32 场独立遭遇、36 种不同 SRD 来源敌人，多场登记机制 Boss，探索含可推理的谜题。适合多次游玩，替代此前首推短篇的 2–4 小时定位；旧剧本和旧房快照保留。

1. G01：冻结 5 尺平面网格，位置/路径/占位/墙体/视线/射程与移动计划；旧战斗不迁移布阵。
2. G02：交互战场、范围预览、点格移动与目标选择；自由描述进入同一审核确认。敌方由 DM 的服务端战术代理控制合法移动与动作。
3. G03：36 种有来源的战役敌人预设、8 章32遭遇、解谜、章间恢复/成长与多个场地机制 Boss。
4. G04：距离旁路、重放/重启、敌方与Boss、整章/战役可达性、真实界面验收后推送。

网格公开简化：单格单位，水平/竖直/对角一格均5尺，斜走不可穿墙角；无高低差、完整体型占格或机会攻击。法术范围只对已登记的配方执行，不由叙述产生范围外命中。战役怪物是基于 SRD 的明确遭遇预设，不冒称自动执行全部官方特性。

每批完成对应验收后 commit。发布目标 v0.10.0；规则全集精修、分队语音仍后移。

## G01

冻结地图/坐标/占位与移动预算，统一武器、施法、治疗及旧能力入口的范围检查。点格和“移动到（列，行）”描述都产生同一待确认计划。敌人走服务端DM战术代理，不能移动玩家；含场地预警和装置机制。新字段缺省不进入旧剧情序列化，避免改写既有作者摘要。

验收：网格14项通过；既有行动计划/公开提案/产品/剧情图/生成91项通过。覆盖非法格、墙角、占位、困难地形、预算、距离旁路、过期提案、聊天、敌方移动、预警避让与旧战斗不迁移。战役与界面联合验收继续推进。
