# v0.9 首个完整冒险

本次目标：首个可从公开入口开团、推进至结局、保存成长并再次使用角色的完整冒险。设计时长 2–4 小时；自动化遍历只能证明可达性，不能冒称真人计时试玩。

采用 2014 版背景与现有原型规则执行能力。完整 SRD 转录、全部技能/法术细节、任意新 NPC 登记和分队语音不纳入本次发布阻断。不启用未签收规则候选包。

## 提交与验收顺序

1. R00：调整发布范围（本文）。
2. R01：原生 v2 发布、冻结依赖、规则版本匹配、运行状态初始化；从正常公开 API 建房开场。
3. R02：原创《雾港：归航之夜》成品剧本、主持节奏与玩家说明；调查、不同进塔路线、可选遭遇、抉择和三个结局。失败仍可前进，AI 离线仍可通关。
4. R03：结局奖励去重、完整成功/失败路径、多人及恢复验收、界面与使用说明。
5. R04：回归与发布证据，版本标记 v0.9，推送当前分支。

每个小版本通过对应验收后独立 commit。真实模型调用继续受本次有限测试预算约束，不保存密钥。

## 发布证据要求

- 全新数据库，经正常发布、选择、建房、开场、检定确认、战斗、路线与结局。
- 成功及关键检定失败均有合法结局；可选生成支线失败时仍有作者路线。
- 1–4 人状态流程、刷新/重启恢复、重试不重复骰点/消耗/奖励。
- 目标时长与实际计时结果分开记录；未完成真人试玩时明确说明。
- Python 回归、相关界面验收和远程提交标识。
