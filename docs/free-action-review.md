# 自由行动独立集成评审

评审日期：2026-10-23。对象：导演提案、自由行动注册表、真实命令 API、房间持久化。模型使用固定 JSON stub，不连接外部 LLM。

## 发现与修复

初版导演将 `Decision.model_dump()` 的所有默认字段传入自由行动验证器，包括 `difficulty`、`skill_id` 等。验证器采用白名单，因此合法自由行动也会失败或退回对话。实施代理已对自由行动执行数据进行规范字段投影，保留原始请求严格拒绝额外数值字段的行为。API 测试确认合法模型输出现在保持 `source=llm`，并能正确执行。

自由行动在副本上结算并替换状态；实施代理同时修正导演随后继续使用旧嵌套对象引用的问题。测试验证执行收据、提案移除、环境结果与房间存储一致。

## 体验与覆盖边界

- 自由文本是行动意图，注册规则负责执行；无法映射、预算不足或不合法时，对话回应必须明确没有机械效果。
- 点燃要求当前存在火源；火焰按战斗回合结束推进，战斗外按自由行动推进。此处独立验证了战斗外持续损坏与重启保存。
- 移动、扬沙、搜索等含抽象规则或房规，预览应展示注册表的成本、判定与限制；不能把有自然语言输入等同于任意物理模拟。
- 本轮独立 API 验证聚焦操作物件、点燃、取消、权限、动作预算和持久化；未逐一复验每个擒抱、推离、掩体、隐蔽组合。相应细节由自由行动模块单元测试覆盖。
- 未执行真实网络模型、浏览器交互、长时并发或所有职业额外攻击组合测试。不能据此声称任意模型输出均会可靠映射或全部 SRD 特殊动作已自动实现。
