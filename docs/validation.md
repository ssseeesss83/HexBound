# v0.3 验证记录

验证日期：2026-10-23。

- `python -m pytest -q`：103 项通过，包括权威骰点与战斗、不同结局、倒地房主推进、并发入席、权限、幂等、过期版本、存档恢复、WebSocket、LLM schema、整体超时和取消处理。
- 三个前端入口 `app.js`、`studio.js`、`account.js` 的 JavaScript 语法检查通过。
- 账号安全测试：注册权限固定、scrypt 与会话哈希、CSRF、完整同源检查、会话期限与撤销、账号禁用、强制改密、最后管理员及并发降级保护、在途撤权、422 密码脱敏。独立评审另行复跑了 28 项账号与房间测试，见 [账号评审](account-review.md)。
- 集成授权测试：默认拒绝游客及旧共享密钥；普通账号携旧密钥也不能绕过角色；创作者可用 Cookie + CSRF 编辑内容但不能管理用户。
- `npm run test:accounts`：真实后端 Cookie 与 DOM 验证注册、登录、改密、全部设备退出、角色管理、搜索分页、禁用、密码重置、强制改密、审计与工坊权限。
- `npm run test:rooms`：六个独立注册账号通过真实 HTTP/WebSocket 创建与加入、满员拒绝、共享骰点、聊天、暂停恢复；新设备登录同一账号可恢复原角色，不依赖本地 Bearer 凭证。
- 新增覆盖：内容 Schema、依赖与图校验、发布与历史、原子导入、归档保护、快照隔离、多敌人、技能资源和分支规则；API 集成验证发布后真实开团、旧房间版本不变、自由创作权限及模型建议不自动执行。
- `npm run test:studio`：通过。真实后端 DOM 流程覆盖管理员鉴权、公开摘要、技能/怪兽/剧情编辑、校验与发布、复制归档、内容包导入导出、历史恢复与开团入口。
- `npm run test:ui`：通过。测试启动独立 FastAPI 实例及临时 SQLite，以 jsdom 执行实际前端脚本，使用真实 HTTP 与 WebSocket。创建与加入、六席同步、第七位拒绝、开始、骰点同步、HTML 输入转义、暂停恢复、非安全上下文 UUID 后备和身份保存均通过。
- 补充 DOM 体验：返回首页并从保存席位恢复已通过。

测试边界：未提供真实 LLM 凭证，因此模型调用使用受控响应与异常进行协议测试，没有对真实模型质量、兼容端点和费用作验证。环境未提供可运行的浏览器渲染器，因此没有完成桌面/移动端截图及真实布局验收；DOM 测试不证明视觉效果。Docker 配置已提供，当前环境未执行镜像构建。
