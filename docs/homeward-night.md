# 《雾港：归航之夜》· v0.9

原创完整冒险，推荐 2–4 人、3 级角色；支持单人。设计目标 2–4 小时（建议约 150–210 分钟），这是主持节奏估计，尚非真人计时结果。单人快速点击会明显更短。

## 开团

启动服务并登录，在“创建冒险”选择《雾港：归航之夜》。邀请同伴，各自完成 3 级构筑，房主开始。建议首次使用战士模板；任何角色都能用探索技能。盐壳守卫是可绕开的弱遭遇，1–4 人使用同一公开数值，不冒称按完整 5e 挑战等级平衡。

队内商量用交流频道；只有实际行动提交后才进入裁定、确认和结算。自由描述与技能入口使用同一挑战账本。同地点同问题全队只检定一次，换措辞或换人不能刷骰。确认前可取消。

## 玩家可读前提

午夜灯塔熄灭，三艘归船困在暗礁外。摆渡人阿苇请你们带回透镜，与拒绝继续守夜的伊岚交涉。救船之外，还要决定未来谁来守灯，以及一座港口是否有权要求一个人永远付出。

每幕先读场景，给每位玩家表达方法或立场的机会，再推选代表提交。不要只连续点击路线；调查、承诺、争执和角色尾声构成主要游玩内容。主持不会偷偷扣除“记忆”等未实现资源。

## 主持节奏与完整路线（含剧透）

| 幕 | 场景与有效选择 | 建议时间 |
|---|---|---:|
| 1–2 | 码头接委托；鱼市决定如何保存文件、回应家属与书记 | 25–35 分钟 |
| 3–4 | 海关对照原誓约；分工修复透镜 | 25–35 分钟 |
| 5–6 | 商量搬运；选择运道或盐径；可绕行或主动打守卫 | 25–40 分钟 |
| 7–8 | 观潮发信号；值班室照顾伤员、明确承诺 | 20–30 分钟 |
| 9–10 | 面对伊岚，讨论修灯、解誓或撤离 | 25–40 分钟 |
| 终幕 | 最终协作检定；各角色分享尾声 | 15–25 分钟 |
| 可选 | 从海关追查送信人，AI 生成短支线后回接海关 | 15–30 分钟 |

主线：码头 → 鱼市 → 海关 → 透镜 → 选路 → 运道/盐径（可选守卫）→ 观潮台 → 值班室 → 伊岚 → 抉择 → 修灯/解誓/撤离 → 结局。

每次关键检定成功记录 1、失败记录 2，任一结果都开放下一幕。没有必须获得的机械物品，不依赖尚未实现的物品授予。守卫站出口由战斗完成门禁控制，击败实体不会因刷新或重访复活。

修灯全胜需要修镜、观潮、交涉、最终校准均顺利；解誓全胜需要文件、观潮、交涉、最终解誓均顺利。否则仍能靠共同守夜救回归船，进入有代价的结局。撤离可直接选择，保住岸上人，两艘船进入浅湾，最后一艘命运留给后续冒险。无人被强制永久牺牲。

## 可选 AI 支线与故障

海关的“追查送信人”只生成眼前一小段，保留续写出口和回接海关的约束。需要部署者配置模型；没有服务时选取消等待，再走“处理裂开的透镜”。支线不承担通关必需证据。生成完成后仍须重新审核确认路线，后台不会替玩家移动。

进入生成支线后，系统额外提供“返回此前的主线场景”。即使模型漏写返回路线或后续生成离线，也可取消当前等待后返回已访问的海关；继续深入时沿已确认的分支来源保留退路。战斗必须先结束，返回不重置检定、资源或奖励。

刷新会恢复房间。跨设备登录后从“我的冒险”返回原席；长时间缺席请暂停等人，本版没有自动接管玩家。服务重启后用原数据库继续，勿删除数据库来解决等待。

## 结算与范围

原生剧本首次结束按 v0.9 房规，每位存活角色获得 300 XP，里程碑模式则获得 1 个成长资格；战斗 XP 另计。重复提交或恢复不重复领奖。保存的人物可再次用于合适起始等级的新房间。

本版使用现有原型规则执行能力。AI 不会执行未支持的技能或法术；规则资料全集尚未签收并激活，不能把目录完整视为全部规则自动化。分队文字权限可用，分队语音本次不实现。
